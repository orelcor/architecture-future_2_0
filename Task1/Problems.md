# Проблемы текущего решения

1. Низкая техническая пригодность легаси-технологий при масштабировании бизнес-вертикалей:
- Power Builder (используется как антипаттерн - как реализация слоя бизнес-логиики)
- Apache Camel (привязка к Java-стеку)
2. Риски лицензий иностранных вендоров:
- Power BI
- MS SQL Server
3. Использование DWH, как единого слоя хранения данных - риски масштабирования бизнес-вертикалей
4. Риски по Data-privacy при работе с вендорскими LLM вроде OpenAI - регуляторные штрафы для бизнеса 
5. ПДн могут обрабратываться за границей - также штрафы
6. Риски утечки данных из-за слабой реализации ролевой модели в шине данных Apache Camel
7. Разнородный стек в доменах (Python, Java, Go) - сложность роста экспертизы и обмена опытом
